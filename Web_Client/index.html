Nội dung gửi qua HTTP POST:


 • HTTP GET: Nhập địa chỉ URL hoặc từ khóa tìm kiếm lên thanh Omnibox.

• HTTP HEAD: Chọn HEAD hoặc bấm nút [HEAD] trên thanh công cụ để chỉ lấy HTTP Response Headers (Body = 0 bytes).

• HTTP POST: Điền biểu mẫu bên trái hoặc bấm nút [POST] để gửi dữ liệu Form / JSON.

• Lịch sử (History - Ctrl+H): Lưu vết, tìm kiếm và lọc các trang đã truy cập.

• Tải xuống (Download - Ctrl+J): Tải trang web / tài liệu về máy qua giao thức HTTP/1.1 (Tải thử trang tài liệu HTTP).

• Kiểm thử mã lỗi 404: Mở đường dẫn không tồn tại (404 Not Found)
