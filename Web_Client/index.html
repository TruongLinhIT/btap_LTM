3. CÁC TÍNH NĂNG TRÌNH DUYỆT (TƯƠNG TỰ CHROME / CỐC CỐC)
• Quản lý Tải xuống (Download Manager): Bấm phím tắt Ctrl + J hoặc nút [⬇ Tải xuống] ở thanh phía trên.
• Lịch sử duyệt web (History): Bấm phím tắt Ctrl + H hoặc nút [🕒 Lịch sử] để tìm kiếm và xem các URL đã vào.
• Developer Tools (F12): Bấm phím F12 hoặc nút [🛠 DevTools] để soi mã trạng thái (200, 404), thời gian phản hồi (ms) và HTTP Headers.
• Hệ thống Đa thẻ (Multi-tabs): Bấm nút dấu + trên thanh tab hoặc phím Ctrl + T để mở thêm thẻ mới; bấm x để đóng thẻ.
• Phân tích URL & Phân giải DNS IP: Bấm nút [🌐 DNS] để xem chi tiết Host, Port, Path và địa chỉ IP InetAddress.
• Kiểm thử Tự động: Bấm nút màu xanh [⭐ TỰ ĐỘNG TEST (12/12 ĐẠT)] ở hàng đầu tiên để chạy kiểm thử và xem bảng kết quả.
